# HORINSA · Planta de hormigón en Lanzarote

Juego de gestión de una planta de hormigón y asfalto en Lanzarote, con vista 3D de toda la isla (carreteras, relieve y costa reales).

Atiende las llamadas de las obras, organiza camiones, chóferes, mecánicos y la planta, cuida al equipo y crece hasta hacerte con la isla. Incluye minijuegos: bomba de pluma, descarga por canaleta y pala cargadora.

**Jugar:** abre `index.html` desde la web publicada con GitHub Pages. Funciona en el ordenador y en el móvil, sin instalar nada.

Datos del mapa: © colaboradores de OpenStreetMap (ODbL). Relieve a partir de un modelo digital de elevación público.
